# Pablo Pizzaria

Site de portfólio para uma pizzaria napoletana fictícia.

- Rolagem suave com Lenis
- Animações de rolagem com GSAP e ScrollTrigger
- Título animado letra por letra com SplitText
- Pizza desenhada em canvas, montada etapa por etapa conforme a rolagem
- Cardápio com rolagem horizontal no desktop e grade no celular

Arquivo único (`index.html`), sem build. Para rodar localmente, basta abrir o arquivo ou servir a pasta:

```bash
python -m http.server 8000
```

Projeto fictício: nome, endereço e telefone são inventados.
